# Inclusive Science website

東洋大学重点研究推進プロジェクト「インクルーシブ・サイエンス」のWebサイトです。

## 現在の状態

- 既存の「プロジェクト概要」ページを `/about/` へ移植済み
- ヘッダー、フッター、共通レイアウトをコンポーネント化
- HOME、組織・メンバー、研究チーム、研究成果、お知らせの入口を作成
- Newsと研究成果用のコンテンツ構造を定義
- Cloudflare Workersで静的配信できる設定を用意

人物写真と代表挨拶は仮表示です。確認済みの情報に差し替えてから公開してください。

## 開発

```sh
pnpm install
pnpm dev
```

## 確認用ビルド

```sh
pnpm build
```

生成結果は `dist/` に出力されます。
