Inclusive Science — プロジェクト概要ページ

確認方法
1. ZIPを展開します。
2. index.html をブラウザで開きます。

ファイル
- index.html：ページ本体と文章
- styles.css：デザインとレスポンシブ対応
- script.js：メニュー、ヘッダー、控えめな表示アニメーション

写真の差し替え
index.html 内の leader-photo-placeholder 要素を画像に置き換えます。
正式なご挨拶文が確定したら provisional-note を削除し、leader-message 内の文章を差し替えてください。

インターネット接続がない場合も表示できますが、Google Fontsが読み込まれず、端末の標準フォントに切り替わります。
